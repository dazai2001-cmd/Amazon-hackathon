# Player tutorial

The Squire’s Field Guide opens on the first visit to the chapter or clan hall. It has five illustrated lessons: phone setup, sword and shield, story objectives/dialogue, Alden’s exercises, and clan wars. Players can follow Next/Previous or jump directly to a lesson. Closing it records onboarding on this browser/device; it does not reset game saves.

Reopen **Player guide** from the chapter title or pause menu, the question-mark button during the story, **Training guide** from Alden’s hall, or **War guide** from multiplayer. The main menu has a dedicated **Player Guide** option beside Settings and Controller Setup.

The setup lesson shows live phone connection, body-in-view and calibration status and can open camera pairing. Pairing and calibration continue hands-free once the player is framed and follows the poses. Exercise setup explains the separate side view and start/lower/return calibration. Desktop preview displays different keyboard instructions and explicitly disables exercise XP.

The guide supports the TV D-pad, Select and Back, along with keyboard Tab/Enter/Escape. Focus stays in the guide while it is open; the underlying interface is inert. Closing restores a usable game/menu focus. Story progression, character dialogue, combat and training counters pause while reading. In a live multiplayer pairing the server pauses both fighters and the guide prominently explains the 30-second forfeit window. An existing manual pause remains in effect when help closes.

Alden’s three playable weapon lessons remain the practical tutorial: hold a shield, make a cut, and lean away then return. The field guide explains how to reach those lessons and the other modes; it does not mark them complete or grant exercise rewards.

Normal TV play uses the Fire TV remote for navigation and the Android phone camera for sword fighting and exercise form. No desktop keyboard is required. In the courtyard, D-pad up/down walks and left/right turns when the 3D view is focused; Select interacts or takes the guided route. Back opens the pause menu, which also offers the journal, training, help and audio settings. Dialogue choices use D-pad and Select, or the optional camera gestures.

In Clan Wars, highlight a name or invite-code field and press Select to open the on-screen keyboard. Use D-pad to highlight letters, Select to type, Clear/Delete/Space/Aa to edit, Done to save, or Back to cancel. Focus returns to the field; use D-pad to continue through the form. Audio sliders use left/right for five-percent steps and up/down to leave the slider. Play/Pause and Menu pause the current activity. Back at the native main menu exits the app.

The main menu's **Settings → 3D resolution** defaults to **Auto**, beginning at Full HD and reducing to a 720p cap after sustained low frame rate. Select cycles Auto, fixed 1080p and fixed 720p. The interface uses the screen's available output resolution in all modes.

For installation requirements, a clean repository setup, emulator configuration and troubleshooting, see [the reviewer guide](REVIEWER_GUIDE.md). Normal camera play needs the running server, a TV/browser screen and an Android phone with Chrome and camera permission; the TV does not need a camera. Wi-Fi camera access requires trusted HTTPS; USB localhost is the alternative development route.
